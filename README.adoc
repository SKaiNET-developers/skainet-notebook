== Overview

*SKaiNET* https://skainet.sk[project]  is an open-source deep learning framework written in Kotlin, designed with developers in mind to enable the creation of modern AI-powered applications with ease. It seamlessly integrates with Jupyter notebooks, providing a powerful environment for interactive data analysis, machine learning experimentation, and model development.

== Features

* Full Kotlin language support in Kotlin Notebooks
* Interactive data visualization capabilities
* Seamless integration with popular ML libraries
* Type-safe data manipulation
* Rich markdown and documentation support

== Using with Jupyter Notebook

=== IntelliJ IDEA

You can create Kotlin notebooks directly in IntelliJ IDEA using one of these methods:

=== Within a Project
* Right-click on source root/folder in Project view
* Select `New` → `Kotlin Notebook`

=== Scratch Notebook
* Press kbd:[Cmd+Shift+N] (macOS) or kbd:[Ctrl+Alt+Shift+Insert] (Windows/Linux)
* Select `Kotlin Notebook`

== Inline image display (Quick Start)

This module provides simple, Kotlin‑idiomatic inline image rendering for Kotlin notebooks, inspired by Python's PIL `display()` ergonomics. See the PRD for context: link:./image-prd.md[Image Rendering PRD].

=== 1) Add dependency

[source]
----
@file:DependsOn("sk.ainet.app:kotlin-notebook:0.4.0")
----

=== 2) Display a BufferedImage

[source]
----
val img = java.awt.image.BufferedImage(128, 128, java.awt.image.BufferedImage.TYPE_INT_RGB).apply {
    val g = createGraphics()
    g.color = java.awt.Color(0x33, 0x99, 0xFF)
    g.fillRect(0, 0, width, height)
    g.dispose()
}

sk.ainet.app.notebook.display.display(img)
----

=== 3) Display from different sources

[source]
----
// From filesystem path (String)
sk.ainet.app.notebook.display.display("/path/to/sample.jpg")

// From bytes
val bytes: ByteArray = java.nio.file.Files.readAllBytes(java.nio.file.Path.of("/path/to/sample.png"))
sk.ainet.app.notebook.display.display(bytes)

// From URL
sk.ainet.app.notebook.display.display(java.net.URL("https://example.com/sample.png"))
----

=== 4) Options DSL (size, alt, border, cssClass)

[source]
----
sk.ainet.app.notebook.display.display(img) {
    width = 256
    height = 256
    alt = "Demo image"
    border = true
    cssClass = null // optional
}
----

=== 5) Multi‑image grid

[source]
----
val imgs = List(4) { idx ->
    java.awt.image.BufferedImage(96, 96, java.awt.image.BufferedImage.TYPE_INT_RGB).apply {
        val g = createGraphics()
        g.color = java.awt.Color((50 + idx * 40) % 255, 120, 200)
        g.fillRect(0, 0, width, height)
        g.dispose()
    }
}

sk.ainet.app.notebook.display.display(imgs) { border = true }
----

=== API Reference (summary)

- Core dispatcher:
  - `display(image: Any, configure: DisplayOptions.() -> Unit = {})`
    - Supports: `BufferedImage`, `ByteArray`, `String` (path), `Path`, `URL`.

- Overloads:
  - `display(img: BufferedImage)`
  - `display(bytes: ByteArray)`
  - `display(path: String)`
  - `display(url: URL)`
  - `display(images: List<Any>, configure: DisplayOptions.() -> Unit = {})` (grid)

- DisplayOptions fields:
  - `width: Int?`, `height: Int?`, `alt: String?`, `border: Boolean`, `cssClass: String?`
  - Non‑functional helpers: `measureTime: Boolean`, simple auto‑downscale guards: `autoDownscaleMaxWidth/Height/Pixels`, and caching flags.

Notes:
- Rendering uses inline HTML `<img>` with base64 data URLs via Kotlin Notebook rich output.
- No Swing windows are used; output is always inline.
- Behavior aims to mirror Python PIL ergonomics: one‑line display, automatic type handling, and REPL‑friendly usage.
